# 秀米成品验收清单

## 保存前：逐段检查实际画面

- [ ] 给定文本按顺序填入，无遗漏、重复或误替换；缺失字段的 `【待补充】` 出现在对应位置，无模板示例文字。续编时已完成区域保持不变。
- [ ] 标题层级、正文、配色、装饰和留白与参考一致；正文与所属标题的关系清楚，同类组件保持统一。
- [ ] 检查长标题及编号、装饰的实际边界：可见、不裁切、换行自然；表格文字与底色可辨。仍无法修正的溢出在交付时说明，按用户要求才在正文标注。
- [ ] 按相邻内容核对章间、表格前后和结尾的分隔符与留白；复合装饰完整。
- [ ] 日程一阶段一行，时间与内容一一对应，无重复阶段或意外空行；如有逐行渐变，各行是纯色，首末行颜色和未指定区域不变。
- [ ] 表格列宽符合信息量；图片未被拉伸，图注对应正确；有链接时对照给定地址核对显示文本和已配置的跳转目标。
- [ ] 章节和内容块可在秀米逐块编辑，不依赖一个覆盖全文的富文本组件。

## 保存后：确认实际持久化

- [ ] 确认目标稿已保存到服务器，再重载；等预期正文或表格加载完成后，读取 DOM 核对正文、原生组件、图片、样式及跳转。仅恢复出本地内容不算通过。
- [ ] 在重载后的画面复看长标题、分隔符与留白、表格入口与末尾、结尾及文末。DOM 中存在文字不代表文字在画面中可见。
- [ ] 返回目标草稿链接，指出 `【待补充】`、`【排版溢出】` 和未能验证的事项（如有）；不自动发布。
